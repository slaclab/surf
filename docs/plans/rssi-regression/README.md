# RSSI Regression Task

SURF RSSI RTL under `protocols/rssi/v1/`.

Start with `plan.md`. Use `progress.md` for day-to-day status, `rtl-changes.md`
for production RTL changes made during the task, and `handoff.md` for compact
resume notes once implementation begins.
